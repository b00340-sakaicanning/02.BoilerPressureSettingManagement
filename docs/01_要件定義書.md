## 1. 目的と範囲

### 1.1 目的
ボイラの圧力設定を変えたときに、その内容をスマホからすぐ記録できるようにする。これまで Excel（`ボイラ圧力設定変更履歴.xlsx`）にためてきた履歴はスプレッドシートへ移し、今後はスプレッドシートとアプリの両方で閲覧できるようにする。

### 1.2 現状の課題
| 項目 | 課題 |
|---|---|
| 記録 | PC の前でないと入力できず、現場で変えた直後に記録しにくい |
| 圧力の値 | 毎回手入力のため、基準パターンと合わない記録がある（4件） |
| 設定者 | 頭文字の表記がそろっていない（`y` と `ｙ`）。マスタにない記入者（`ヒ`、退職済み）がいる |
| 変更理由 | 生産品種の書き方がばらばらで、品種ごとに探しにくい |
| 時刻 | 文字列と時刻の値が混在し、並べ替えや絞り込みが正しく動かない |
| 閲覧 | 今の設定がどれか、すぐに分からない |

### 1.3 範囲
| 区分 | 内容 |
|---|---|
| 対象 | 圧力設定の変更をスマホから記録する |
| 対象 | 既存の履歴154件（2025/01/21〜2026/11/12）とマスタをスプレッドシートへ移す |
| 対象 | アプリで今の設定、履歴（一覧と絞り込み）、基準パターン表を見る |
| 対象 | 登録した記録を修正・削除する（権限に応じて） |
| 対象外 | 通知、集計画面とグラフ、ボイラ本体や計器とのデータ連携（D-18） |

## 2. 利用者と役割

| 役割 | 想定する人 | できること |
|---|---|---|
| 設定者 | ボイラの圧力設定を変える担当者 | 記録の登録、閲覧、アプリで登録した自分の記録の修正（期限なし。D-09） |
| 管理者 | 設備担当の責任者など（1〜2名。D-25） | 上記に加えて、全件の修正（移行データを含む。D-11）、削除、元に戻す、操作ログの閲覧 |

- 設定者は入力者マスタからプルダウンで選ぶ（自己申告。Google ログインはしない。D-05）。表示は「記入称（氏名）」（D-23）。
- 管理者モードは、管理者共通の暗証番号（K-02）で入る。30分有効（D-29）。
- 権限の詳細は docs/04 第1部 §2。

## 3. 機能要件

### 3.1 記録の項目
| 項目 | 必須 | 入力方法 |
|---|---|---|
| 日付・時刻 | ○ | 初期値は今の時刻。変えられる |
| 設定パターン | ○ | 基準パターンマスタから選ぶ |
| メインボイラ | ○ | 「ガス」「重油」のどちらか（号機ではなく燃料の種類） |
| 設定圧力(MPa) | ○ | パターンを選ぶと自動で入り、手で直せる。マスタと違うときは注意を出す（D-01）。0.50〜0.80（D-26） |
| 設定者 | ○ | 選んでいる操作者 |
| 生産品種 | 任意 | 品種マスタから選ぶ（D-03） |
| 備考 | 任意 | 自由記述。200文字まで（D-16） |

- 記録には圧力の値そのものを保存する。マスタをあとで改定しても、過去の記録は変わらない（D-15）。
- サブ圧力と号機は記録しない（D-02）。
- 項目の定義は docs/03 §2.1、入力チェックは docs/04 第1部 §4。

### 3.2 画面
| 画面 | 内容 |
|---|---|
| ホーム | 今の設定（最新の記録）を大きく表示。直近5件 |
| 入力 | 3.1 の項目。登録前に確認する |
| 履歴 | 新しい順の一覧。期間・パターン・燃料・設定者・品種で絞り込む。1ページ20件（設定で変えられる）でページを切り替える |
| 記録の詳細 | 全項目の表示。権限に応じて修正・削除・元に戻す |
| パターン表 | パターンごとのメイン圧力・サブ圧力・主要品種 |
| 管理者モード | 暗証番号で入る。削除済みの表示、操作ログ |

画面構成は docs/02 §3、細部は plan/05。

### 3.3 スプレッドシート
- 記録・マスタ・設定・操作ログをシートに持つ（docs/03）。
- 履歴シートは、人が見る項目を左（A〜I 列）に置き、スプレッドシートでも閲覧できるようにする（K-13）。
- マスタはスプレッドシートで直接編集する。消さずに有効フラグを外す（D-17）。

### 3.4 既存データの移行
- Excel の履歴154件と、基準パターン・入力者のマスタを移す。品種マスタは新しく作る（D-20）。
- 主な方針（D-21、D-22、D-28）:
  - 時刻を "HH:mm" にそろえる。
  - 読み仮名を取り除く。
  - 記入称は半角英数にそろえる（入力者マスタの全角「ｙ」を半角「y」にする。2026/11/15 の依頼）。
  - 「ヒ」は無効の人として登録する。
  - パターンと圧力が合わない4件は、値を変えずに移す。
  - 備考から生産品種を振り分ける（元の文字列は備考に残す）。
- 移行後の Excel は、読み取り専用で保管する（D-27）。
- 手順と規則は docs/04 第1部 §13。

## 4. 非機能要件

| 区分 | 要件 |
|---|---|
| 同時に使ったとき | LockService で書き込みを順番に処理する。修正は版数で楽観ロックする（D-19） |
| 履歴を残す | 登録・修正・削除・認証を操作ログに残す。削除は論理削除 |
| バックアップ | 毎月1回、スプレッドシートを複製する。12か月分を残す（K-21） |
| 性能 | ホームの表示は3秒以内を目安にする。件数の見込みは年に約90件 |
| 使う環境 | iPhone の Safari、Android の Chrome、PC の Chrome / Edge。幅375pxを基準にする |
| 公開範囲 | 全員がアクセスできる。使えなければ組織内（D-24） |
| 安全 | 管理者暗証番号はハッシュ化して保存する。デプロイ ID とスクリプト ID は文書に書かない |
