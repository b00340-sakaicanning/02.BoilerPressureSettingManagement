## 1. 共通の方針

- 1行目を見出し行にし、固定する。データは2行目から入れる。
- コードでは、列を**見出し名で探す**。見出し名とキーの対応は Code.gs の定数 `COLUMNS` に持つ。列の順番が変わっても動くようにするため。
- 型の凡例:

| 記号 | 型 | 書式 |
|---|---|---|
| T | テキスト | `@`（書式なしテキスト） |
| D | 日付 | `yyyy/mm/dd` |
| DT | 日時 | `yyyy/mm/dd hh:mm:ss` |
| HM | 時刻の文字列 | `@`、値は "HH:mm"（K-01） |
| N | 数値 | 圧力は `0.00`、それ以外は `0` |
| B | 真偽値 | TRUE / FALSE |

- 日時はすべて Asia/Tokyo で扱う。画面に返すときは文字列にする（`yyyy/MM/dd HH:mm`）。
- 「操作者」は入力者ID（U01 など）で持つ。システムが行った操作は `SYSTEM` にする。

### 1.1 シート一覧

| シート名 | 定数キー | 用途 | 更新方法 |
|---|---|---|---|
| 圧力設定変更履歴 | RECORDS | 記録の本体 | アプリ（移行時はメニュー） |
| 基準パターンマスタ | PATTERNS | パターンごとの基準の圧力 | 人が直接編集 |
| 入力者マスタ | OPERATORS | 設定者 | 人が直接編集 |
| 品種マスタ | PRODUCTS | 生産品種の選択肢 | 人が直接編集 |
| 設定 | SETTINGS | アプリの設定値 | 人が直接編集（管理者パスワードはここに置かない。§3.5） |
| 操作ログ | LOGS | 登録・修正・削除などの記録 | アプリ（追記だけ） |

- 「初期設定」メニュー（`menuSetup`）で、シートと見出しを作る。何度実行しても、重複して作らない。
- どのシートも「編集時に警告を表示」で保護する（K-14）。

## 2. 記録のデータ

### 2.1 圧力設定変更履歴（RECORDS）

A〜I 列が人の見る項目、J 列以降がシステム用の項目（K-13）。

| # | 列 | 見出し | キー | 型 | 内容 |
|---|---|---|---|---|---|
| 1 | A | 日付 | date | D | 変更した日 |
| 2 | B | 時刻 | time | HM | 変更した時刻 "HH:mm" |
| 3 | C | 設定パターン | pattern | N | パターン番号 |
| 4 | D | メインボイラ | fuel | T | `ガス` / `重油` |
| 5 | E | 設定圧力(MPa) | pressure | N | 小数2桁 |
| 6 | F | 設定者 | setterName | T | 記入称（保存した時点のもの。該当入力者が下線持ちならセル書式にも下線を設定する。フェーズ10） |
| 7 | G | 生産品種 | product | T | 品種マスタの品種名。空でもよい |
| 8 | H | 備考 | note | T | 200文字まで |
| 9 | I | マスタとの差異 | masterDiff | B | 保存した時点のパターンのメイン圧力と違えば TRUE（K-09） |
| 10 | J | 記録ID | recordId | T | `BP-yyyyMMdd-NNN`（K-05） |
| 11 | K | 変更日時 | changedAt | DT | 日付＋時刻。並べ替えと絞り込みに使う |
| 12 | L | 設定者ID | setterId | T | 入力者ID。移行データで設定者が空欄なら空 |
| 13 | M | データ区分 | source | T | `移行` / `アプリ` |
| 14 | N | 移行元行 | sourceRow | N | 移行データだけ。Excel での行番号（2〜155） |
| 15 | O | 登録日時 | createdAt | DT | |
| 16 | P | 登録者ID | createdBy | T | 移行データは `SYSTEM`（K-18） |
| 17 | Q | 更新日時 | updatedAt | DT | 登録時は登録日時と同じ |
| 18 | R | 更新者ID | updatedBy | T | |
| 19 | S | 版数 | version | N | 登録時1、更新のたびに＋1 |
| 20 | T | 削除フラグ | deleted | B | 論理削除 |
| 21 | U | 削除日時 | deletedAt | DT | |
| 22 | V | 削除者ID | deletedBy | T | |

- 条件付き書式: 削除フラグが TRUE の行は、文字を灰色（`#94a3b8`）にし、取り消し線を付ける。マスタとの差異が TRUE の I 列は、背景を `#fef3c7` にする。
- J〜V 列は列のグループにして、初めは折りたたんでおく。
- 記録は末尾に足す。行は物理的に消さないので、行の位置は変わらない（K-12）。

### 2.2 操作ログ（LOGS）

| # | 見出し | キー | 型 | 内容 |
|---|---|---|---|---|
| 1 | ログID | logId | T | uuid |
| 2 | 日時 | loggedAt | DT | |
| 3 | 操作者ID | operatorId | T | 入力者ID、または `SYSTEM` |
| 4 | 操作者 | operatorName | T | 記入称（`SYSTEM` のときは「システム」） |
| 5 | 役割 | role | T | `設定者` / `管理者` / `システム` |
| 6 | 記録ID | recordId | T | 記録に関係ない操作では空 |
| 7 | 操作 | action | T | 日本語の操作名（04 §12） |
| 8 | 内容 | detail | T | JSON の文字列 |

追記だけにして、更新・削除はしない。

## 3. マスタと設定

### 3.1 基準パターンマスタ（PATTERNS）

| # | 見出し | キー | 型 | 内容 |
|---|---|---|---|---|
| 1 | パターン | pattern | N | 番号（重複不可） |
| 2 | メイン圧力(MPa) | mainPressure | N | |
| 3 | サブ圧力(MPa) | subPressure | N | 表示だけに使う |
| 4 | 主要品種 | products | T | 表示用の文字列 |
| 5 | 注記 | note | T | |
| 6 | 改定日 | revisedAt | D | 空でもよい |
| 7 | 表示順 | sortOrder | N | |
| 8 | 有効 | active | B | FALSE は入力の選択肢に出さない |

初期データ（Excel の基準パターンマスタから。主要品種は品種名だけを取り出す）:

| パターン | メイン | サブ | 主要品種 | 注記 | 表示順 | 有効 |
|---|---|---|---|---|---|---|
| 1 | 0.66 | 0.64 | 小型 | 2024.7.19時点 | 1 | TRUE |
| 2 | 0.67 | 0.65 | 1.5L、2L水&SP、2L(麦茶以外) | 2024.11.22時点更新 | 2 | TRUE |
| 3 | 0.68 | 0.66 | 2L(麦茶)、CUP有 | 2024.11.22時点更新 | 3 | TRUE |
| 4 | 0.69 | 0.67 | （空） | | 4 | TRUE |
| 5 | 0.65 | 0.63 | 小型 | 2025.1.29新設（メイン0.70→0.65に変更） | 5 | TRUE |

- 主要品種は Excel の文字のまま取り込む。新しい品種名（D-20）に合わせるのは、取込のあとにユーザーが手で直す（取込はパターンマスタを CSV の内容で置き換えるため、先に直すと消える）。

### 3.2 入力者マスタ（OPERATORS）

| # | 見出し | キー | 型 | 内容 |
|---|---|---|---|---|
| 1 | 入力者ID | operatorId | T | `U01` 〜（重複不可。一度振ったら変えない） |
| 2 | 記入称 | shortName | T | 例: h、y、Y（英数字は半角。y と Y は別の人。セルのフォント下線書式を判定して認識する。フェーズ10） |
| 3 | 氏名 | fullName | T | |
| 4 | 表示順 | sortOrder | N | |
| 5 | 有効 | active | B | FALSE はプルダウンに出さない |
| 6 | 備考 | note | T | 例: 退職 |

初期データ: Excel の入力者マスタの7名を、その並び順で U01〜U07 にする。氏名の読みの誤りは直す。8人目として、記入称「ヒ」を U08、有効 FALSE、備考「退職」で足す（D-06）。氏名は移行 CSV（`operators.csv`）から取り込み、計画書には書かない。

### 3.3 品種マスタ（PRODUCTS）

| # | 見出し | キー | 型 | 内容 |
|---|---|---|---|---|
| 1 | 品種名 | name | T | 重複不可 |
| 2 | 表示順 | sortOrder | N | |
| 3 | 有効 | active | B | |

初期データ（D-20）: 小型(0.35〜1.0L)、小型(水、スポーツ)、1.5L(お茶)、1.5L(水、スポーツ)、2L(麦茶あり)、2L(麦茶なし)、2L(水、スポーツ)、その他（この順で表示順 1〜8、すべて有効。2026/11/15 の修正依頼で12から8つへ集約し、CUP有を無くした。2L は 麦茶あり → 麦茶なし → 水、スポーツ の順）。

### 3.4 設定（SETTINGS）

見出しは「キー」「値」「説明」。「値」の列は書式なしテキスト（`@`）にし、値はすべて文字列で持つ（「0.50」が「0.5」に変わらないようにするため）。数値として使うときは、コードの `getSettingNumber_` で変換する。

| キー | 初期値 | 説明 |
|---|---|---|
| APP_TITLE | ボイラ圧力設定管理 | 画面のタイトル |
| ENV | 開発 | `開発` / `本番`（K-27） |
| RECORD_ID_PREFIX | BP | 記録ID の頭の文字 |
| PRESSURE_MIN | 0.50 | 設定圧力の下限（D-26） |
| PRESSURE_MAX | 0.80 | 設定圧力の上限 |
| NOTE_MAX_LENGTH | 200 | 備考の最大文字数 |
| PAGE_SIZE | 50 | 操作ログを1回に読む件数 |
| HISTORY_PAGE_SIZE | 20 | 履歴の1ページの件数（5〜100 の整数。範囲外は20。K-11） |
| RECENT_COUNT | 5 | ホームに出す直近の件数 |
| FUTURE_WARN_MINUTES | 10 | これより先の日時は注意する（K-08） |
| AUTH_TOKEN_MINUTES | 30 | 管理者トークンの有効時間 |
| PIN_MAX_FAILS | 5 | 管理者パスワードを続けて間違えてよい回数（キーの名前は前の版のまま） |
| PIN_LOCK_MINUTES | 15 | 間違えすぎたときのロック時間 |
| MIGRATION_FOLDER_ID | （空） | 移行 CSV を置くフォルダ |
| BACKUP_FOLDER_ID | （空） | バックアップの保存先 |
| BACKUP_KEEP_MONTHS | 12 | バックアップを残す月数 |

- 画面に返してよいのは、APP_TITLE、ENV、PRESSURE_MIN、PRESSURE_MAX、NOTE_MAX_LENGTH、PAGE_SIZE、FUTURE_WARN_MINUTES、AUTH_TOKEN_MINUTES だけ。パスワードやフォルダの ID は返さない。
- 前の版の `ADMIN_PIN_SALT`・`ADMIN_PIN_HASH` は使わない（フェーズ9）。残っている行は手で消す（docs/05 §1.8・§3.5）。残っていても動きは変わらない。

### 3.5 スクリプトプロパティ
GAS エディタの「プロジェクトの設定 → スクリプト プロパティ」に置く。開発と本番の GAS プロジェクトで別々に持つ。

| プロパティ | 値 | 内容 |
|---|---|---|
| ADMIN_PASSWORD | 持ち主が決める（2文字以上。文字の種類は自由。前後の空白は無視） | 管理者パスワード。無い・2文字未満なら、誰も管理者モードに入れない。初期値は置かない |

## 4. 移行 CSV の形式

`tools/migrate/convert_excel.js` が `reference/移行データ/` に出力する。ユーザーは、そのうち4つの CSV を移行用フォルダ（MIGRATION_FOLDER_ID）に置く。

- 文字コードは UTF-8（BOM なし）、改行は LF、1行目は見出し（英字のキー）。

| ファイル | 列 |
|---|---|
| records.csv | sourceRow, date(yyyy/MM/dd), time(HH:mm), pattern, fuel, pressure(0.00), setterName, product, note |
| patterns.csv | pattern, mainPressure, subPressure, products, note, sortOrder, active |
| operators.csv | operatorId, shortName, fullName, sortOrder, active, note |
| products.csv | name, sortOrder, active |
| report.md | 変換レポート（件数、内訳、時刻の変換、設定者の置き換え、品種の振り分け結果、該当しなかった備考の一覧）。取り込まない |

- 取込の手順と照合は 04 §13。
