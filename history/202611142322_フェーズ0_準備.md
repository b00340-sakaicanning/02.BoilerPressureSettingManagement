## tools の変更点
- `gas_fakes.js`
  - Shift_JIS の変換を消し、UTF-8 だけにした。既定のスプレッドシート名を `ボイラ圧力設定DB_開発` にした。
  - 足したもの: `Folder.getFilesByName`、`File.getDateCreated`、`Range.shiftColumnGroupDepth`、`Sheet.getColumnGroup`、`Sheet.setConditionalFormatRules` / `getConditionalFormatRules`、`SpreadsheetApp.newConditionalFormatRule`、`helpers.queuePrompt` / `setLockAvailable` / `addFolder` / `sheetState`、ダイアログのボタン定数（YES/NO）
  - ゴミ箱のファイルは、本物の GAS に合わせて一覧に含めたまま（Code.gs 側で `isTrashed()` を確かめる前提）。
- `run_tests_node.js`: マスタ取込を消した。`menuSetup` と `seedDevData` は、関数があるときだけ呼ぶ。Tests.gs から `__FAKES__` でフェイクの補助を使えるようにした。
- `build_local_preview.js`: バナーを、操作者のプルダウン、管理者モード、データ初期化に変えた。タイトルの置き換えを、どのタイトルでも動くようにした。
- `preview_mock.js`: 書き直した。保存キーは `boilerMock_v1`、`boilerPressure.operatorId`、`boilerPressure.adminToken`。ハッシュ引数は op / admin=1 / open。まだ無い関数は呼ばない。通信中の件数を `window.__gasPending` に出す。
- `mobile_frame.html`: 既定を `tab=home&op=U01`、高さを 2000px にした。
- `browserDriver.js`: 待ち合わせの判定を `#loading-overlay` と `__gasPending` に、通知の記録を `.toast` にした。グラフ用の処理を消した。
