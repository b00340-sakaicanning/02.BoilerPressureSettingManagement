# 07 タスク一覧

- 版: v1.0（2026/11/14。初版）
- 元資料: 構築手順 6章、02〜06
- 役割: フェーズごとのタスクと完了条件。進み具合をここで管理する

フェーズを終えるたびに、次の5つを行う。
1. 終わったタスクを `[x]` にする。
2. 変わった仕様を docs に反映する。
3. `history/YYYYMMDDhhmm_フェーズN_内容.md` を作る（タスク、テスト結果の表）。
4. 画面を変えたら `node tools/build_local_preview.js` を実行する。
5. GAS エディタへの貼り替えが必要なファイルを列挙する。

各タスクの見方: 「【セクション】や対象ファイル」「（参照する章）」。テストは各フェーズの最後に書く。
