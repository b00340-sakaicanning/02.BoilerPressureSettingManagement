# 12. 入力者マスタ記入称の下線表示（フェーズ10）

- 版: v1.0（2026/11/16）
- 依頼: 入力者マスタにある記入称の下線（アンダーライン）を、GASアプリ側でも表示できるようにする（2026/11/16）
- 決めたこと（2026/11/16 ユーザーと合意）

| No | 内容 | 決定 |
|---|---|---|
| C-1 | マスタの下線判定 | スプレッドシートの「入力者マスタ」シートの B列（記入称）セルのフォント書式（`getFontLines()`）から自動取得する（案A）。列の増設はしない |
| C-2 | 履歴シートへの書式反映 | アプリから新規登録・修正した際、スプレッドシートの「圧力設定変更履歴」シートの F列（設定者）セルにも、該当者であれば下線書式（`underline` / `none`）を設定する（1行ずつの書き込みのため体感遅延なし） |
| C-3 | プルダウン内の表記 | ブラウザの制約で下線スタイルが反映されない `<select>` の `<option>` 内では、下線付きの入力者を `y (下線)(氏名)` または `y (下線)` と表記する |
| C-4 | 画面での表示範囲 | アプリ画面上では、「記入称」の文字部分のみに下線を引く（氏名には引かない） |

---

## 1. 現状と技術方針

### 1.1 スプレッドシート側（Code.gs）
- **入力者マスタの読み取り**:
  - `readAll_('OPERATORS')` または `getOperators_()` において、B列（記入称）の `Range.getFontLines()` を取得する。
  - 値が `'underline'` の行について、各入力者オブジェクトに `isUnderline: true`（それ以外は `false`）を付与する。
  - 入力者マスタは10名程度のため、`getFontLines()` による取得オーバーヘッドは数ミリ秒〜十数ミリ秒程度で極めて軽微。
- **履歴シート（RECORDS）への書き込み**:
  - `createRecord`（新規登録）および `updateRecord`（修正で設定者変更時）において、対象行の F列（設定者）セルに対して `cell.setFontLine(isUnderline ? 'underline' : 'none')` を適用する。
  - 単一行に対する API コールが1回増えるだけ（約0.05秒程度）であり、体感速度を損なわずに要件を満たせる。
- **クライアントへの返却データ**:
  - `getInitialData` の `operators` 配列に `isUnderline` を含める。
  - `getRecord` や `listRecords` で返す記録オブジェクト（`setterId`）から、クライアント側でマスタを参照して下線描画を行う。

### 1.2 画面側（css.html / js.html）
- **スタイリング（css.html）**:
  - 下線表示用クラス `.is-underline` を定義する。
    ```css
    .is-underline {
      text-decoration: underline;
      text-underline-offset: 2px;
    }
    ```
- **表示共通関数（js.html）**:
  - XSS を防止しつつ安全に下線を HTML 描画できるよう、以下の共通関数を整理・新設する。
    - `operatorHtml(o)`: 入力者の HTML 表示（例: `<span class="short is-underline">y</span>(山田)`）
    - `setterHtml(r)`: 記録の設定者の HTML 表示（記録の `setterId` に紐づく入力者が下線持ちなら記入称に `.is-underline`）
    - `operatorOptionText(o)`: `<select>` 内のテキスト表示（下線持ちなら `y (下線)(山田)`）
    - `operatorLabel(o)`: プレーンテキスト（ダイアログのタイトルや属性用）
- **表示箇所の修正**:
  - ヘッダーの操作者チップ
  - 操作者選択モーダル（ボタン内の記入称バッジ）
  - ホーム画面（「今の設定」カードの設定者、直近の履歴の設定者）
  - 入力タブ（設定者表示ボックス、登録確認モーダル）
  - 履歴タブ（一覧カードの設定者、詳細モーダル、削除確認モーダル）
  - 修正モーダル（設定者表示ボックス、管理者向け設定者セレクトボックス）
  - 履歴絞り込みパネル（設定者セレクトボックス）
  - 管理者操作ログモーダル（操作者名）

## 2. 影響範囲の整理

| 対象 | 影響 |
|---|---|
| スプレッドシート | 列の追加・変更はなし。入力者マスタの記入称セルの下線書式を読み取る。履歴シートのF列に下線書式を書き込む |
| 既存データ | 既存のデータ・記録は壊さない（下位互換性あり） |
| 処理速度 | 入力者マスタ取得時・登録時に各1回のAPI呼び出しが増えるのみで、実用上の影響なし |
| ローカル検証・テスト | `gas_fakes.js`、`preview_mock.js`、`Tests.gs`、`run_tests_node.js` でのモック・テスト対応が必要 |
