## 1. 調べて分かったこと
- 3つのアプリは、色・角丸・影の CSS 変数がすでに同じ（Tailwind の Sky と Slate）。違うのは、部品の形とフォント。
- エネルギー使用量集計はアイコンが絵文字。ロッカーとこのアプリは線の SVG。**参考の中心はロッカー**にし、エネルギー使用量集計からは、ロゴの四角とサブタイトル、表の見出しの色だけを借りる。
- ロッカーの管理者パスワードの弱いところは写さない。
  - 未設定のときに `admin123` で通る → このアプリは、未設定なら誰も入れない
  - 照合が画面側だけ → このアプリは、今までどおりサーバー側で照合し、トークン（30分）とロック（5回で15分）を残す

## 3. 管理者パスワード（Code.gs・js.html）
- 保管場所: スクリプトプロパティ `ADMIN_PASSWORD`。持ち主が GAS エディタの「プロジェクトの設定 → スクリプト プロパティ」で入れる・変える。
- 照合: `authenticateAdmin(operatorId, password)`。入力の前後の空白は取る。
  - プロパティが無い・2文字未満 → AUTH_FAILED「管理者パスワードが設定されていません（GAS エディタのスクリプト プロパティ ADMIN_PASSWORD に2文字以上で設定してください）」。失敗の回数には数えない
  - 違う → 今までどおり失敗を数え、5回で15分ロック（設定キー `PIN_MAX_FAILS`・`PIN_LOCK_MINUTES` は名前を変えずに使う）
  - 合う → トークンを発行（`AUTH_TOKEN_MINUTES` 分）
- やめるもの: メニュー「管理者暗証番号を設定」、`setAdminPin_`、`menuSetAdminPin`、設定キー `ADMIN_PIN_SALT`・`ADMIN_PIN_HASH`。操作ログの「管理者暗証番号の設定」は、前のログを表示するために名前だけ残す。
- 初期設定の結果に、`ADMIN_PASSWORD` が未設定なら「スクリプト プロパティ ADMIN_PASSWORD を設定してください」と出す。
- 画面:
  - 「暗証番号」を「パスワード」に変える（M-15「パスワードが違います」など）
  - 認証のダイアログ: 鍵の丸いアイコン、見出し「管理者認証」、説明「管理者パスワードを入力してください。認証すると{n}分間、すべての記録の修正・削除ができます」、入力欄の薄い字「管理者パスワードを入力」、ボタン「キャンセル」「認証する」
  - 2文字未満なら、サーバーに送らずに「パスワードは2文字以上です」
  - {n} と M-12 の分数は、設定 `AUTH_TOKEN_MINUTES`（画面に返す設定に足す）から出す

1. 開発環境

2. 本番（指示があってから）
   1. **先に**スクリプト プロパティ `ADMIN_PASSWORD` を入れる（先に Code.gs を貼ると、入れるまで管理者モードに入れない）
   2. Code.gs・index.html・css.html・js.html を貼り替え、「デプロイを管理 → 編集 → 新バージョン」
   3. 設定シートの2行を消す
   4. 利用者に、管理者パスワードの変更を伝える
